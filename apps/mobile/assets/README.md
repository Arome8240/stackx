# Assets Directory

This directory contains app assets like icons and splash screens.

## Required Assets

### Icon (icon.png)
- Size: 1024x1024px
- Format: PNG with transparency
- Used for: App icon on home screen

### Adaptive Icon (adaptive-icon.png)
- Size: 1024x1024px
- Format: PNG with transparency
- Used for: Android adaptive icon

### Splash Screen (splash.png)
- Size: 1284x2778px (or larger)
- Format: PNG
- Background: #020617 (slate-950)
- Used for: App launch screen

## Generating Assets

Use Expo's asset generation tools:
```bash
npx expo-optimize
```

Or use online tools like:
- https://www.appicon.co/
- https://makeappicon.com/
